# OMID AI-Based Farm Disease, Pest, Yield, and Frost Detection System

Senior Design team: Andrea Dall'Ara, Bridget Trout, Dang Luu, Cyrus Speicher.

## 1. Project overview

OMID combines vineyard sensor readings and crop imagery to support frost warnings, disease and pest screening, bunch counting, yield estimates, and controlled data exports.
